# Code of conduct

## The short version

Be decent. Assume the person on the other end is trying to do good work.

## What that means here

**Argue about the work, not the person.** Technical disagreement is welcome and useful.
"This assertion is wrong because X" is a contribution. "You clearly don't understand X"
is not, and it makes the first kind harder for everyone else to offer.

**Say what you actually found.** If a check passes for the wrong reason, say so. If you
broke something, say so. This project exists because silent wrongness is expensive, and
that applies to the project itself as much as to the products it tests.

**Take the size of the ask into account.** This is maintained in spare hours. A patient
issue gets a better answer than an urgent one.

Harassment, personal attacks, and demeaning comments about anyone are not welcome, in
issues, pull requests, commit messages, or anywhere else this project is discussed.

## Reporting

Raise it with the maintainer through
[GitHub](https://github.com/Sikkandar-Sha/VirtualOrg). For anything you would rather
not put in a public issue, use a
[private security advisory](https://github.com/Sikkandar-Sha/VirtualOrg/security/advisories/new),
which is private between you and the maintainer even though it lives under Security.

Reports will be read and acted on. Maintainers who do not follow this themselves should
expect to be told so.
